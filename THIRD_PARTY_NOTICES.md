# Third-party notices

This is the attribution ledger for Build Once.

## Current status (v0.1)

**No third-party code or text is included in this kit as of v0.1.** Everything here was written for this project, with two exceptions that are not "third-party material" in the copying sense:

- `LICENSE` is the unmodified text of the Apache License, Version 2.0, published by the Apache Software Foundation, which is how that licence is meant to be used.
- The CI workflow *downloads* the open-source tools `gitleaks` (MIT licence) and the GitHub Actions `actions/checkout` and `actions/setup-node` (MIT licence) when it runs. They are used, not copied into this repository.

## Policy

1. **Ideas are fine; copying needs a record.** We learn from public projects — patterns, approaches, lessons. Re-expressing an idea in our own words and code needs no entry here.
2. **Any copied snippet must be logged here**, in the same pull request that adds it, with:
   - what was copied and where it now lives in this repo,
   - the source (a link to the exact file or page, and version or commit),
   - its licence,
   - its copyright line, exactly as the source gives it.
   Keep any licence header that came with the snippet.
3. **Only copy from compatible permissive licences** (for example MIT, BSD, Apache-2.0), and follow their terms.
4. **Never copy from:**
   - AGPL (or GPL) sources,
   - code or text with **no licence** (no licence means "all rights reserved", not "free"),
   - proprietary, leaked or paywalled sources,
   - AI output that you have reason to think reproduces someone else’s code word for word.
5. When unsure, do not copy. Write it yourself, or ask in the pull request.
