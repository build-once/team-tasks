# Decision: no app-store app for now

Date: 15 October 2026. Decided by: Raj Dhonota (owner).

**The decision.** Team Tasks stays a web app people open in a phone's browser. We are
not building an iPhone or Android app, so there is no store account, no review queue and
no signing key to look after.

**Why.** It is for one volunteer group of about six. A website reaches both kinds of
phone at once, and a change goes live when a pull request merges rather than when a store
approves it.

**What would change it.** Any one of these:

- notifications on a phone's lock screen;
- working with no signal;
- somebody using the app asking for an installable one.

**Not a claim about phones.** Nobody has checked these screens on a real phone yet
([#176](https://github.com/build-once/team-tasks/issues/176)).
